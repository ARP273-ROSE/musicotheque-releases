# What changes, version after version

New features described from the point of view of what they change for you.
Technical details stay in the code repository. Earlier versions are described
in French only: see [CHANGELOG.md](CHANGELOG.md).

MusicOthèque updates itself: at start-up it checks whether a more recent
version exists and offers to install it. You have nothing to download.

---

## 3.22.1 — Quiet fix
*14 October 2026*

- A feature that was only used on the maintainer's computer is no longer part
  of the distributed program. Nothing changes for you.

---

## 3.22.0 — Mac and Linux, full English, new look
*14 October 2026*

- **Mac and Linux**: MusicOthèque now also installs on a Mac (Apple Silicon
  and Intel) and on Linux, with the same look everywhere. Three features
  exist only on Windows — burning a CD, the inserted audio CD, Apple Music
  playlists: on Mac and Linux, their menu entry is greyed out and a tooltip
  says why.
- **Your library is safer**: it is now kept in your personal folder, apart
  from the program. Reinstalling MusicOthèque can no longer erase it. This
  happens by itself, in an instant, on the first start of this version:
  nothing to do, nothing changes on screen.
- **Everything in English** for those who chose English: many messages were
  still in French. The help is available in English too.
- **A look that no longer shifts**: same colours and same (more readable)
  font on every computer, whatever the system's theme and settings.
- **One single logo**, the golden double quaver: the window still showed the
  old vinyl record.
- **A printable manual**, in French and English, with real pictures of the
  application: menu **Help → Manual (PDF)**.
- Update notes are shown in the chosen language.
