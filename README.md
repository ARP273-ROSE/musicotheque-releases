# MusicOthèque — téléchargements

Ce dépôt ne contient aucun code : il sert uniquement à **distribuer**
l'application MusicOthèque pour Windows.

## Installer

Allez sur la page **[Releases](../../releases/latest)** et téléchargez le
fichier `MusicOtheque-Setup-X.Y.Z.exe`, puis lancez-le.

L'installation se fait dans votre profil utilisateur : aucun mot de passe
administrateur n'est demandé. Au premier démarrage, l'application cherche
votre bibliothèque iTunes et propose de tout importer (morceaux, listes de
lecture, podcasts).

> Windows peut afficher « Windows a protégé votre ordinateur » au premier
> lancement, parce que l'installeur n'est pas signé. Cliquez sur
> **Informations complémentaires** puis sur **Exécuter quand même**.
> Cet avertissement n'apparaît qu'une seule fois : les mises à jour suivantes
> sont installées par l'application elle-même et ne le déclenchent pas.

## Mettre à jour

Ne téléchargez rien : MusicOthèque vérifie elle-même s'il existe une version
plus récente et propose de l'installer.

Le fichier `musicotheque-app-X.Y.Z.zip` attaché à chaque version est destiné à
cette mise à jour automatique ; il ne s'installe pas à la main.
